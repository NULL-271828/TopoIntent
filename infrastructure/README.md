# Infrastructure paths

1. Default: unprivileged CPU Linux, local Python environment, real BGE-M3 and released evidence. No author-server access.
2. Optional: privileged disposable Linux/Mininet host, from released XML or generated scripts.
3. Full: multi-GPU 72B inference host plus separate privileged network host.

See [hardware](hardware.md), [Mininet](mininet_public_infrastructure.md), [full GPU](full_gpu_reproduction.md), and [current host constraint](no_sudo_server_constraint.md).
